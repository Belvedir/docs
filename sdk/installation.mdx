The Belvedir Node SDK auto-instruments the major LLM providers with a single `initialize()` call.

## Install

```bash
npm install belvedir
```

Coming from `@fractalresearch/loop`, `@belvedir/loop`, or `belvedir-loop`? See [Migrating from Fractal](/migrating-from-fractal).

Both SDKs run on macOS, Linux, and Windows with no native dependencies. The Node SDK is pure TypeScript and needs Node 18 or later; the [Python SDK](/sdk/python) is pure Python and needs 3.10 or later. For setting `BELVEDIR_API_KEY` per operating system, see [Environment variables](/guides/environment-variables).

## Initialize before importing your LLM SDK

The SDK patches your LLM client the moment `initialize()` runs, so `initialize()` must run **before the LLM SDK is imported**. Call it once at process start. In a plain CommonJS Node process, that is the top of your entry file:

```ts
import { initialize } from "belvedir";

initialize({
  apiKey: process.env.BELVEDIR_API_KEY!,
  appName: "my-agent",
});

// import OpenAI/Anthropic *after* initialize()
```

Never call `initialize()` from inside a route or handler file: by then the LLM SDK is already imported and the patch won't take. In Next.js, the only place guaranteed to run first is `instrumentation.ts` at your project root; see the [Next.js guide](/guides/nextjs).

## ESM and bundled code: pass `instrumentModules`

In an ESM entry point (`.mjs`, or `"type": "module"` in `package.json`) and in any bundled environment (Next.js, webpack, esbuild), **always pass your LLM SDKs via `instrumentModules`**. Static imports hoist above the `initialize()` call and dynamic `import()` bypasses the require hook, so auto-instrumentation produces no LLM spans there, with no warning. Pass only the SDKs you actually use; either the SDK class or the module namespace is accepted:

```ts
import { initialize } from "belvedir";
import OpenAI from "openai";
import * as anthropic from "@anthropic-ai/sdk";

initialize({
  apiKey: process.env.BELVEDIR_API_KEY!,
  appName: "my-agent",
  instrumentModules: { openAI: OpenAI, anthropic },
});
```

In Next.js, also keep the LLM SDKs and `belvedir` itself out of your bundles with `serverExternalPackages`, so every bundle shares one runtime copy; see [Keep LLM SDKs external](/guides/nextjs#keep-llm-sdks-external).
