The SDK auto-instruments these LLM providers with zero additional code:

- OpenAI
- Anthropic
- Cohere
- Azure OpenAI
- Amazon Bedrock
- Google Vertex AI
- Replicate
- HuggingFace

Local models via [Ollama](/inference/local-models) and hosted OpenAI-compatible endpoints ([Together](https://together.ai), [Fireworks](https://fireworks.ai), [Groq](https://groq.com), [OpenRouter](https://openrouter.ai), self-hosted [vLLM](https://docs.vllm.ai)) work through the OpenAI SDK. See [Hosted Inference](/inference/hosted).
