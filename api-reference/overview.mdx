The Belvedir REST API accepts OpenTelemetry trace data as OTLP over HTTP, in JSON or protobuf. The SDK calls it automatically; you rarely need to hit it directly.

- **Base URL**: `https://platform.belvedir.ai`
- **Authentication**: API key via `Authorization: Bearer` or `x-api-key` header. See [Authentication](/api-reference/authentication).
- **Endpoints**:
  - Tracing: [`POST /api/v1/traces`](/api-reference/traces), [`POST /api/v1/outcomes`](/api-reference/outcomes)
  - Inference: [`POST /api/v1/route/chat/completions`](/api-reference/route) (OpenAI-compatible), [`POST /api/v1/messages`](/api-reference/route) (Anthropic-native passthrough), [`POST /api/v1/route/embeddings`](/api-reference/route), and [`POST /api/v1/route`](/api-reference/route) for a routing decision without execution
  - Batches: [`/api/v1/route/batches`](/api-reference/route) (`POST` to create, `GET` to list the project's recent batches, plus per-batch status, results, cancel, and uploads) and the Anthropic-SDK-compatible facade at `/api/v1/messages/batches` (create, list, retrieve, results, cancel, and `DELETE /api/v1/messages/batches/{id}` to remove an ended batch and its stored results)
