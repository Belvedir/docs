---

Every API request carries your Belvedir API key. Keys start with `bv_live_` and are shown once at creation; store them securely. Keys belong to the project: create and revoke them on the **API Keys** page.

## Bearer token

```bash
curl https://platform.belvedir.ai/api/v1/traces \
  -H "Authorization: Bearer bv_live_..."
```

## x-api-key header

```bash
curl https://platform.belvedir.ai/api/v1/traces \
  -H "x-api-key: bv_live_..."
```

Both headers are accepted on every endpoint. Choose whichever fits your HTTP client.

## Anthropic SDK clients

The Anthropic SDK sends `x-api-key` when you set `apiKey` (or `ANTHROPIC_API_KEY`) and `Authorization: Bearer` when you set `authToken` (or `ANTHROPIC_AUTH_TOKEN`); Belvedir accepts either, so both env vars work as the key carrier with `ANTHROPIC_BASE_URL=https://platform.belvedir.ai/api`. See [Messages](/api-reference/messages).
